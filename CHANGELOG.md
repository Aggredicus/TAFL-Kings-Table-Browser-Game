# Changelog

## 1.0.0 — 2026-10-27 — First public release
- Seven playable presets: Copenhagen and Fetlar Hnefatafl, Tablut, Brandubh, Tawlbwrdd, Ard Rí, Alea Evangelii.
- Eight original, culturally inspired visual themes, automatic matching and manual persistence.
- Local pass-and-play, heuristic computer opponent and manual cross-device match-code exchange.
- In-app research and QA with 31 regression checks, including equal-height board row bug fix.
- GPL-3.0 source release, documented rule uncertainty and runtime privacy constraints.

### Version history clarification
The private development package was labeled v2.0. This is the first public release, numbered 1.0.0. Export protocol `TA2` and persistence key identifiers are intentionally unchanged.

### Known limitations
Copenhagen exit-fort and fully closed encirclement require human adjudication; Alea Evangelii layout is an explicitly interpretive modern arrangement; complex repetition and rare throne captures require further tournament-rule review. No automatic network multiplayer is provided.
